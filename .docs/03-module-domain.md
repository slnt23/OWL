# domain 模块：领域核心

## 定位

存放核心业务模型和领域服务，是项目的"数据模型中心"。遵循 DDD 思想，保持纯业务、无框架依赖。

## 结构

```
xyz.nanian.owl
├── dto/
│   └── PageDTO.java     ← 通用分页请求对象
└── vo/                  ← 通用值对象（待扩展）
```

## 依赖关系

- 依赖 `common`（使用工具类）
- 不依赖 `api`（保持纯净）
- 被 `api` 和所有业务模块依赖

## 设计原则

- 只放跨业务的通用模型
- 各业务模块特有的实体放在各自模块的 `domain.entity` 包中
- 业务逻辑集中，便于测试和重构
