# OWL 文档中心

本文档是 OWL 仓库的文档入口。所有写入 `.docs` 的文档都应遵守[《OWL 文档编写规范》](standards/documentation-standard.md)。

## 文档地图

| 路径 | 内容 | 负责人 |
| --- | --- | --- |
| [README.md](../README.md) | 项目总览、技术栈、快速启动 | 仓库 Owner |
| [ADR 目录](adr/) | 架构决策记录，文件名为 `adr-XXX-*.md` | 对应模块 Owner |
| [数据库目录](database/) | DDL、表结构说明、示例数据 | 数据库 Owner |
| [手册目录](manual/) | 模块使用、开发指南 | 对应模块 Owner |
| [运维目录](ops/) | 部署、CI/CD、故障处理 | DevOps / Ops Owner |
| [规范目录](standards/) | 文档、代码、流程等强制规范，含[代码注释规范](standards/code-comment-standard.md) | 仓库 Owner |

## 文档职责

| 文档类型 | 回答的问题 | 维护要求 |
| --- | --- | --- |
| 仓库 README | 这是什么项目、如何快速跑起来 | 技术栈或启动方式变化时同步更新 |
| ADR | 为什么做这个架构决策、放弃了哪些方案 | 决策变化时新增或废弃记录，不重写历史 |
| 开发手册 | 按什么步骤完成某类任务 | 步骤或依赖变化时同步更新 |
| 运维文档 | 如何部署、如何恢复故障 | 环境、命令或流程变化时同步更新 |
| 规范文档 | 必须遵守的边界是什么 | 规则变化时先评审再发布 |

## 生命周期速查

正式文档按 `草稿 -> 评审中 -> 已批准 -> 已废弃` 演进；状态和负责人写在文档头部。任何文档变更都通过 PR 评审，不允许绕过评审直接合入。

## 红线

- 禁止在文档中提交密码、Token、私钥、真实个人信息。
- 禁止把聊天记录或问答原文直接粘贴为正式文档。
- 禁止复制粘贴代码或表结构作为唯一事实来源，应链接到源码。
- 禁止让文档长期停留在“已过时但未标记”的状态。
